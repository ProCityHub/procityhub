```

```

This can be rewritten in cosh form:

```
V_φ = [2 · O · √(A·B) / (A + B)] · cosh((α - β)/2 · ln(A/B))

```
V_φ = V_QM · cosh((α - β)/2 · ln(A/B))

## Key Properties

1. **Symmetric paths (A = B):** V_φ = V_QM = O. The models are identical.
2. **Asymmetric paths (A ≠ B):** V_φ > V_QM. The models diverge.
3. **The divergence grows with asymmetry:** As A/B → 0 or ∞, V_φ → ∞ while V_QM → 0.
4. **No free parameters:** α and β are fixed by the golden ratio. There is nothing to tune.
